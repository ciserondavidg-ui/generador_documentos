CORRESPONDENCIA PDF — INSTALACIÓN
1. Sube index.html, plantillas.json y la carpeta plantillas al repositorio GitHub. Activa Pages desde main / root.
2. En Google Cloud Console crea o selecciona un proyecto, habilita Google Sheets API, configura la pantalla de consentimiento OAuth y crea un ID de cliente OAuth de tipo aplicación web. Añade el origen https://TU-USUARIO.github.io (sin ruta) a orígenes JavaScript autorizados. Si está en modo prueba agrega los usuarios autorizados. No uses un secreto de cliente en HTML.
3. Abre Pages, pega el Client ID en la aplicación y pulsa Guardar enlace. Selecciona gestor y Cargar / actualizar Google Sheets. Cada usuario debe tener permiso de lectura de la hoja completa. El selector no restringe permisos por pestaña.
4. Carga un DOCX con campos {{NOMBRE}}. Se guarda automáticamente en IndexedDB del navegador. Para compartir una plantilla sin datos personales, sube el DOCX a plantillas/ y agrega una entrada en plantillas.json, por ejemplo {"nombre":"Convenio","archivo":"plantillas/convenio.docx"}. Actualiza catálogo en la aplicación.
5. Selecciona los campos/columnas y descarga PDF individual o ZIP de PDF. La captura manual es independiente de la selección masiva; para un registro de Sheets usa Desde/Hasta con el mismo número.
NOTAS: PDF generado como imagen por página; puede variar frente a Word y el texto no es seleccionable. Comprueba documentos largos y saltos de página. No se ha probado la autenticación real ni la conversión visual con tus plantillas. No publiques datos de clientes. El acceso a Sheets es de solo lectura y el token se conserva en memoria de la sesión.
